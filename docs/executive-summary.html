Why the earlier “Predicted values must be in range [0, 1]” rejection cannot happen with this file

  • Values are written from a float64 array that is checked to be inside [0, 1] with a 1e-6 round-off tolerance before writing; anything larger raises instead of clipping silently (src/gems/submission_writer.py).
  • The shipped raster contains only 0.0 and 1.0 inside the footprint (verified by re-reading the file from disk in the validator output).
  • NaN appears only outside the official footprint, and the footprint is taken from the organiser’s own sample_submission.tif finite mask, not from a guessed feature mask.
  • Single band, float32, EPSG:32611, 3730×3292, 100 m, transform copied from the reference file.
